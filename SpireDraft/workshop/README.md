# SpireDraft — official ModUploader workspace template

This directory follows the official Mega Crit uploader layout. **It is a template, not a playable or ready-to-upload mod**: `content/SpireDraft.dll` is missing until `Build.cmd` completes. Do not upload this directory as it stands.

| Path | Purpose |
|---|---|
| `workshop.json` | Steam Workshop title, visibility, tags, RitsuLib Workshop dependency |
| `image.png` | Workshop cover, under 1 MiB |
| `content/SpireDraft.json` | In-game mod manifest and in-game RitsuLib dependency |
| `content/SpireDraft.dll` | Compiled code; generated by `Build.cmd` in `dist/`, not present here |

Run `Build.cmd` from the source package. It creates `dist/SpireDraft-stable/` or `dist/SpireDraft-beta/` as a complete uploader workspace. Verify the game behavior, then run `Upload.cmd` or call `ModUploader.exe upload -w "<absolute path to dist/SpireDraft-stable>"`. The uploader sends only the files under `content/` as mod content.

The uploader creates `mod_id.txt` in the **same workspace** after the first successful upload. Keep that file to update the same item. Keep `visibility` as `private` until you are ready to publish. For full instructions, read `../README.zh-CN.md`.
